# mpv-playback-history

mpv 的**播放历史 / 续播**插件：把你播过的本地文件与网络流记下来（路径、标题、进度、时长、时间），
用 [uosc](https://github.com/tomasklaen/uosc) 风格的菜单浏览、管理，并一键从上次的位置接着看。

A playback-history & resume plugin for mpv, with a uosc menu.

---

## 特性

- **多条目历史**：不像 mpv 自带的 `watch_later` 只记最后一次，这里保留任意多条（默认上限 500）。
- **进度真的丢不了**：周期写盘 + 暂停时写盘 + 退出时写盘三重落盘；退出那一刻先从内存快照取数据
  （mpv 在 `shutdown` / `end-file` 时属性已经读不到，动态读会得到 `nil`，插件因此改用了快照）。
- **按来源分层**：本地文件按**父文件夹**分组，网络流按 **URL host** 分组；host 可用 `source_names` 起别名。
- **菜单里能干完所有事**：`..` 回父文件夹、行内上移/下移/删除、文件夹内清空、点击即播并自动关窗。
- **设置项也能在 mpv 里改**：不必去翻配置文件，菜单里点着换档，改完自动写回 `script-opts/*.conf`。
- **空启动续播**：mpv 空着启动时，空格 / 回车 / 鼠标左键 = 续播最近一条记录。
- **只记真播过的**：播放不足 `min_play` 秒（只被加载、没真播的）不入历史，杜绝「幽灵条目」。
- **标题只升级不降级**：退出瞬间 `media-title` 已失效，插件不会因此把好标题换成 URL 末段的 id。
- **网络流兜底**：点了一个已经失效的地址，6 秒内起不来就自动停掉并说明原因，不会晾在界面上。
- **多实例安全**：多个 mpv 同时开着时合并写盘 + 删除墓碑，不会互相把对方的记录写没。

## 安装

依赖 **[uosc](https://github.com/tomasklaen/uosc)**（已装可跳过）。把两个文件放进 mpv 配置目录：

```
<mpv 配置目录>/
├── scripts/
│   └── playback_history.lua        ← 来自本仓库 scripts/
└── script-opts/
    └── playback_history.conf       ← 来自本仓库 script-opts/
```

`<mpv 配置目录>` 按你的安装方式：

| 方式 | 路径 |
|---|---|
| 便携版 | mpv 程序同级目录下的 `portable_config/` |
| Windows | `%APPDATA%\mpv` |
| Linux / macOS | `~/.config/mpv`（macOS 也支持 `~/Library/Application Support/mpv`） |

**重启 mpv 生效**（脚本只在启动时加载）。装好后控件条会多出一个「播放历史」按钮。

## 使用

### 快捷键

| 操作 | 说明 |
|---|---|
| `Ctrl+H` | 打开播放历史菜单（可改，见下） |
| `空格` / `回车` / `鼠标左键` | **仅空启动时**：续播最近一条记录 |

想换快捷键，在 `input.conf` 里加一行（注意脚本名里的连字符要写成下划线）：

```
Ctrl+H  script-binding playback_history/open
```

### 播放历史菜单

- 第一行 `..` 回到上一层；本地按文件夹、网络按来源分组。
- 悬停某条时行内出现 **↑ 上移 / ↓ 下移 / 删除** 三个按钮。
- 每层的「清空」按钮清空**当前文件夹**的记录；最外层另有「设置」。
- 点条目直接续播，并自动关闭菜单。
- 条目标着「仅记录」= 该地址已判定为失效（置灰，不可点）；标着「需 XXX 运行」= 需要对应的调用程序在场。

### 设置

菜单最外层 → **设置**，逐项行内换档，改完即写回 `script-opts/playback_history.conf`。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| `save_interval` | `1800` | 播放中每隔多少秒把进度写盘（暂停/退出另有即时落盘） |
| `min_resume` | `30` | 记录进度少于这个秒数就不自动续播（避免开头误续） |
| `max_items` | `500` | 历史上限，超出淘汰最旧的 |
| `min_play` | `3` | 新建条目所需的最小播放秒数 |
| `idle_prefer_local` | `yes` | 空启动续播时，若最近一条是需要外部程序在场的网络流，改用最近一条本地记录 |
| `stream_play` | `auto` | 网络记录能否点播：`auto` 自动判断 / `always` 全可点 / `never` 全置灰 |
| `source_names` | 空 | 网络来源别名，`host=名字`，逗号分隔（如 `192.168.1.9=家里的NAS`） |
| `file` | 空 | 历史文件路径，留空 = `<配置目录>/playback_history.json` |

## 存储格式

单个 JSON 文件（默认 `portable_config/playback_history.json`），方便手改和备份：

```json
{
  "entries": [
    {
      "path": "D:\\Videos\\某剧 S01E05.mkv",
      "dir": "D:\\Videos\\某剧",
      "title": "某剧 - S01E05",
      "pos": 1425.6,
      "dur": 1582.7,
      "ts": 1791182907,
      "ord": 10
    }
  ]
}
```

`ord` 是手动上下移动产生的排序权重，`ts` 是最后一次观看时间，`dir` 仅本地条目有。
**这个文件坏了不会导致 mpv 打不开**：解析失败时插件按空历史处理。

## 与飞牛影视（FnTV）配合

[飞牛影视](https://www.fnnas.com/) 用 mpv 播放时，片源地址是它自己在本机起的中继：

```
http://127.0.0.1:22345/api/v1/playvideo/<itemGuid>?session=<一次性令牌>
```

插件对这个形态做了三件事：

1. **按 `itemGuid` 归一** —— `session` 每播一次就换，不归一的话同一集会在历史里堆成好几行；归一后地址更新为最新一次。
2. **自动归到「飞牛影视」分组**，可显示成「需飞牛影视运行」。
3. **清洗飞牛写入的占位标题** —— 集标题为空时 FnTV 会填字面量 `noTitle`，显示前剥掉，老记录读盘时一并自愈。

⚠️ **飞牛关掉之后这些记录播不动**，这是设计使然：中继只在飞牛影视进程活着时才存在。
插件会明确提示「飞牛影视没有运行，或该播放会话已过期」，不会假装能播。

插件本身**不依赖飞牛**，纯本地文件或别的网络流（Plex / Jellyfin / Emby 会被自动识别出来）一样正常工作。

## 已知限制

- **必须有 uosc**。菜单与按钮走 uosc 的 `open-menu` / `set-button` 接口，没有 uosc 就只有快捷键和落盘功能。
- 「空启动续播」用空格/回车/左键时，会**同时**占用这三者的默认行为（仅在 mpv 空着、没有播放列表时生效）。
- 网络地址的**可播放性无法离线确定**。`stream_play=auto` 只能按「是不是临时签名链接 / 是不是本机中继」做保守判断，
  真正的验证发生在点击之后（6 秒兜底）。
- 播放列表本身不记录，「把整个文件夹装进列表继续」是把目录下的文件重新喂给 mpv。

## 开发与测试

插件是**单文件 Lua**，没有构建步骤。改完直接重启 mpv 即可。

本项目自带的回归方式是「隔离配置目录 + 断言尾巴」：造一个临时 `--config-dir`，把断言代码直接追加在被测文件末尾
（这样能访问所有顶层 `local`），跑一次 `mpv --idle=yes`，再把结果读出来数 `PASS/FAIL`。

```
mpv --config-dir=<隔离目录> --vo=null --ao=null --no-video --idle=yes --msg-level=all=error
```

⚠️ 两个坑：`--idle=no` 会在脚本加载前就退出（什么都跑不到）；`--msg-level=all:error` 写法会让 mpv 直接退出，要用 `all=error`。
